Settings

YouTube API Key required
Get a free key at console.cloud.google.com → Enable "YouTube Data API v3" → Credentials → Create API key.
JSONBin API Key optional — for sync
Free at jsonbin.io → sign up → API Keys. Leave blank to disable cross-device sync.

YouTube API Key
Go to console.cloud.google.com → New project → Enable APIs → search "YouTube Data API v3" → Enable → Credentials → Create API key. Restrict the key to your domain to prevent abuse.

Playlists
Tap + Playlist on the home screen. New Local creates a playlist inside Vantage — add any video from search via “+ Playlist”. YouTube imports a public YouTube playlist by ID or URL.

Ad Block
While a video plays, tap AD to cover the screen and mute. It auto-dismisses after the set delay. Tap the ⚙ icon next to AD to adjust opacity, hole size, and delay.

Sync across devices
Tap Sync on the home screen and enter the same code on every device. Requires a free JSONBin API key (optional). Watch progress syncs automatically.

Watch Later
On any search result tap Watch Later. The card on the home screen shows saved videos. Tap ··· on the Watch Later card to clear the list.
